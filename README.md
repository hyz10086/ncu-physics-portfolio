```text
    ├── week-08/  README.md       # 液体黏滞系数的测定（落球法）
    ├── week-09/  README.md       # 惠斯通电桥测电阻
    ├── week-10/  README.md       # 电位差计的原理与使用
    ├── week-11/  README.md       # 示波器的使用与 RC 电路研究
    ├── week-12/  README.md       # 霍尔效应测磁场
    ├── week-13/  README.md       # 分光计的调节与使用

    ├── week-15/  README.md       # 光电效应测定普朗克常量
    └── week-16/  README.md       # 综合设计性实验与学期项目答辩
```

### 单个实验文件夹的推荐结构

```text
labs/week-XX/
├── README.md      # 实验报告（目的 / 器材 / 原理 / 数据 / 结论）
├── data/          # 原始数据（表格、仪器导出文件）
├── code/          # 数据处理脚本（Python / MATLAB）
└── images/        # 装置照片、数据图表、波形截图
```
